# 가격 비교와 근거 확인 (v0.7.0)

기존 디자인·5개 데이터 메뉴·4개 결과 탭·평가 카드·패널 조절·챗봇 동작을 유지합니다. 전역 CSS나 새 UI 라이브러리를 추가하지 않습니다.

## 사용

AI에게 질문하기에서 “실린더 라이너 업체별 단가를 시장 참고가격과 비교해줘”라고 입력합니다. 이후 “A업체의 +12%는 어떻게 계산됐어?”, “D업체는 왜 비교에서 제외됐어?”, “가격 차이를 설명하는 계약이나 견적 근거가 있어?”처럼 질문하면 현재 선택 품목과 분석 조건으로 설명합니다. 모델은 qwen3:8b입니다.

비교표·차트·평가 카드·보고서는 같은 `PriceAnalysis`를 사용합니다. 분석 ID·가격 버전·데이터 ID·기준일을 확인할 수 있습니다. 평가 카드는 기존 거래·운영 이력의 평가 기간과 점수/비율을 구분하며 원래 점수·등급·산식을 유지합니다. 평가점수는 시장가격 보정이나 높은 단가의 정당화 근거가 아닙니다.

“외부 완성부품 견적”을 펼쳐 두 번째 가상 외부 견적의 1,000,000을 1,040,000으로 바꾸고 Enter를 누르면 중앙값이 1,020,000으로 바뀝니다. 관련 결과 탭·이력은 다시 계산됩니다. 가격 변경 중인 이전 설명 요청은 중단하고, 이미 받은 설명은 이전 버전임을 알립니다. 다시 질문하면 현재 값으로 답변합니다. 브라우저 사용자별 저장과 기존 내보내기를 유지하며 가격 분석 Excel에는 견적 판정·문서 근거·API 참고 시트를 포함합니다.

## 계산과 자료 구분

- 내부: 기존 계약·발주·평가와 별도로 신규 가상 견적을 추가했습니다. 기존 계약단가를 덮어쓰지 않으므로 왼쪽 계약단가와 신규 비교 견적은 다를 수 있습니다.
- 외부: 실제 외부 완성부품 거래자료가 없어 가상 외부 견적 98/100/102만원과 조건 문서를 제공합니다. 등록 협력사 평균을 외부 가격으로 쓰지 않습니다.
- API: Frankfurter의 ECB 제공 USD/KRW 값을 고정 경로로 조회합니다. 출처·관측일·조회 시각·단위·통화·실패 상태를 표시합니다. 실제 원자재·가격지수 API는 미연결이며 기존 시세·임금 화면은 SAMPLE입니다. API 지표는 완성부품 가격·중앙값·보정계수로 사용하지 않습니다.

품목·도면·규격·재질·가공·검사·수량·단위·통화·가격 기준일·세금·운송·납품 조건 13개를 확인합니다. 누락은 ‘조건 확인 필요’, 불일치는 ‘비교 제외’입니다. 유효 외부 견적의 중앙값을 구하고 `차액 = 협력사 단가 − 중앙값`, `차이율 = 차액 / 중앙값 × 100`으로 계산합니다. 견적이 없거나 유효하지 않으면 null과 사유를 표시하고 순위를 만들지 않습니다.

기본 예제는 중앙값 100만원, A +12만원/+12%, B +5만원/+5%, C −2만원/−2%입니다. D는 업체명 조건 없이 검사 내용 차이로 제외됩니다. 현재 시점 견적만 있으므로 가격 추이를 만들지 않습니다.

## RAG 범위

가격 질문은 웹 화면의 문자열 품목·협력사·견적 ID와 계산값을 전용 `/api/rag/price-explanations`로 전송합니다. 정수 키를 사용하는 별도 구매 DB에 임의로 대응하지 않습니다. 서버는 조건과 중앙값·차액·차이율을 재검증하고, BGE-M3로 정확히 연결된 조건 문서를 검색한 뒤 qwen3:8b로 정성 설명을 만듭니다. 숫자는 코드가 표시하며 LLM이 생성한 숫자는 설명에서 차단합니다.

현재 가격 조건 문서는 SAMPLE 7건입니다. 문서 식별자만 같아도 업체·품목·레코드·제목·날짜·페이지·조건이 다르면 연결하지 않습니다. 문서가 없거나 가격 차이의 원가 사유가 기재되지 않으면 관련 근거를 찾지 못했다고 표시합니다. 일반 구매 DB 질문은 기존 별도 DB를 사용하며 채팅에 그 범위를 구분합니다.

CSV/JSON 업로드는 기존 11종 표 기능을 유지합니다. 업로드 후에는 새 데이터 ID를 발급하고 가상 외부 견적·조건 문서를 자동 연결하지 않습니다. 따라서 실제 외부 견적 및 누락된 계약 조건이 없는 업로드 자료는 계산 불가/조건 확인 필요가 정상입니다. 현재 외부 견적 UI는 기본 가상 견적의 금액 편집을 지원하며, 실제 외부 견적 파일 업로드·원문 PDF 파싱은 구현 범위에 포함하지 않습니다.

서명 방문자 쿠키·세션 격리·한도·만료·취소를 기존 중계와 동일하게 적용합니다. 가격 요청에만 UTF-8 256 KiB 제한을 사용합니다. 상세 API는 [PRICE_API.md](../purchase-rag/backend/PRICE_API.md)를 참고하세요.

## 검증

`npm run typecheck`, `npm run build`, `npm run test:logic`, `npm run test:rag`, `npm run test:hosting`, `npm run test:price`와 Python backend/deployment 단위 테스트를 실행합니다. `tests/price-e2e.py`는 모의 게이트웨이로 UI 상태와 수정·저장·보고서 일치를 확인하고, 실제 BGE-M3/qwen3 연결 검증은 별도로 수행합니다. 수정 전후 1920·1366·900·400 화면을 동일 상태에서 비교합니다.
