아직 승인된 평가셋이 아닙니다. 기존 60문항을 검토용으로 정리하고 복수 근거·비교·명확화 질문 4개를 추가했습니다. 모든 항목은 미검토입니다. 성능 재측정, BGE-M3 교체, 운영 임계값 변경은 하지 않았습니다.

먼저 합의할 평가 방식

  1. 실제 업무 질문 확인: 팀원이 평소 묻는 문장을 모으고, 이 데이터로 처리할 범위를 정합니다. 아래 문장을 실제 업무 표현으로 고쳐주세요.
  2. 정답 검토: 질문마다 요구한 사실, 원본 레코드, 필수 조건, 허용할 문서 조합, 거절 사유를 확인합니다. 가능하면 작성자와 별도의 업무 담당자가 교차 검토합니다.
  3. 시험 종류 분리: 의미 검색, ID/날짜 정확 조회, 근거 없음 거절, 여러 근거가 필요한 계산, 애매한 질문 처리를 따로 채점합니다. 모델만 시험하는 조건과 전체 백엔드 조건을 섞지 않습니다.
  4. 개발/조정/최종 검증 분리: 기존 60문항은 이미 결과를 본 개발 자료입니다. 새 업무 질문으로 최종 검증셋을 만들고 모델·임계값을 고정한 뒤 사용합니다. 같은 사실의 말바꾸기 질문은 같은 그룹에 둡니다. 결과를 보고 수정했다면 그 시험은 다시 개발 자료가 됩니다.
  5. 평가 조건 고정: DB 스냅샷, 문서화 코드, 청킹, 모델 버전, 검색 개수, 필터 사용 여부를 기록합니다. 숫자 ID/날짜 조회는 SQL·필터 방식도 비교 기준에 넣습니다.
  6. 합격 기준 사전 합의: 잘못된 근거를 통과시키는 비용과 정상 질문을 거절하는 비용을 정합니다. 오류 종류별 허용치를 검토 후 정하며, 이 문서에서는 임의의 합격률을 확정하지 않습니다.
