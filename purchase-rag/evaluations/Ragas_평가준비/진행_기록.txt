위 승인은 해당 검토 문서와 설정에 대한 실행 승인입니다.

실행 도구: Ollama 0.40.11
생성 모델: qwen3:8b, gemma3:4b, llama3.1:8b
채점 모델: qwen3:14b
양자화: 모두 Q4_K_M (원본 모델별 부가 구성은 다름)

실행 환경 보정:
첫 Qwen3 8B GPU 자동 분할 실행에서 CUDA_Host 메모리 할당 실패 발생.
답변 생성에 성공하기 전 실패했으며 점수로 집계하지 않음.
비교 모델과 채점 모델을 모두 CPU-only(num_gpu=0), 4스레드로 실행.
질문·근거·프롬프트·temperature·seed·입력/출력 한도는 유지.
모델별 학습 대화 템플릿과 stop 토큰은 각 모델 공식 패키지에 따름.

평가 라이브러리: Ragas 0.4.3, 공식 ragas.metrics.collections 사용.
Ollama와 BGE를 연결하는 어댑터는 로컬 구현, 지표 계산식·채점 프롬프트는 수정하지 않음.
외부 유료 API나 실제 API 키를 사용하지 않음.
Ragas 익명 사용 통계 전송 비활성화.

메모리 관리:
모델을 하나씩 실행하고 완료 후 메모리에서 내림.
AnswerRelevancy의 BGE 임베딩은 별도 단계에서 계산하고 캐시.
실제 임베딩이 없는 경우 점수를 만들지 않고 계산 대기 상태로 기록.
채점 모델이 만든 질문은 캐시한 뒤 동일한 공식 지표로 최종 점수 계산.

유의점:
기존 개발 질문에 대한 예비 평가이며 독립 최종 성능 검증이 아님.
모델별 크기가 달라서 같은 규모 모델끼리의 비교는 아님.
채점 모델은 Qwen 계열이고, 같은 계열에 대한 편향 가능성이 있음.
채점 예외는 0점으로 바꾸지 않고 오류와 성공 문항 수를 따로 기록.
Ragas 점수만으로 출처의 정확성이나 모든 숫자의 정확성을 보장하지 않음.

채점 실행 보정: CPU 시험 결과는 *.cpu-attempt로 별도 보존. GPU 20레이어 분할은 로딩 및 예열 후 응답 성공. 생성 모델은 CPU 그대로, 공통 채점 모델은 GPU20/CPU나머지로 고정해 전 문항 재채점. judge_cache는 설정을 키에 포함하므로 CPU 시험 캐시와 혼용하지 않음.
